# Security Policy

## Supported Versions

Security updates are currently provided for the latest stable release of `enough.`.

| Version | Supported |
| ------- | --------- |
| 0.4.x   | Yes       |
| < 0.4   | No        |

## Reporting a Vulnerability

If you believe you have found a security vulnerability in `enough.`, please report it privately by email to:

**[hpmine@web.de](mailto:hpmine@web.de)**

Please do not publicly disclose the vulnerability before it has been reviewed and, where appropriate, fixed.

When reporting a vulnerability, please include as much relevant information as possible, such as:

* A description of the vulnerability
* Steps to reproduce the issue
* The affected version or component
* Any relevant logs, code references, or proof of concept

You should receive an acknowledgement as soon as reasonably possible.

If the vulnerability is confirmed, it will be investigated and addressed according to its severity and impact. Security fixes may be released as part of a subsequent version of `enough.`.

Please do not use this address for general support, feature requests, or non-security issues.
